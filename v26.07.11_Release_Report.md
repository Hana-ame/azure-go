# v26.07.11 Release Report

## Summary
Switch from `refresh_token` OAuth flow to `client_credentials`, add `client_secrets.txt` support, change all API endpoints to use specific user context, and rename `access` → `access_token` file.

## Changes

### Authentication (breaking)
- **Flow**: `refresh_token` → `client_credentials` (grant type)
- **Secret**: reads `client_secrets.txt` instead of env var
- **Scope**: `offline_access Files.ReadWrite.All` → `https://graph.microsoft.com/.default`
- **Persistence**: `access_token` file replaces `access`; `refresh_token` file removed
- **Fix**: removed `Origin` header from token request (caused `AADSTS9002326`)

### API Endpoints (breaking)
All `/me/drive/...` changed to `/users/{user_id}/drive/...`:
- `Upload`, `Get`, `Delete`, `CreateUploadSession`, `Put`, `GetByPath`, `HeadByID`, `HeadByPath`, `DeleteByPath`

### Agent
- Added `user_id` field (from `.env`)
- Added `driveRoot()` helper method
- Added `tokenResponse` struct for JSON parsing
- Raw response body logged on token refresh

### Files
- `AGENTS.md`: project state documentation
- `client_secrets.txt`: new required file (Azure Client Secret)
- `access_token`: new name for token persistence file
- `access`: removed
- `refresh_token`: no longer used

## Diagnostics
All `[TokenRefresh]` logs now include raw response body for debugging.

## Build
`CGO_ENABLED=0 go build -o temp` (static binary for VPS glibc compatibility)

`v26.07.11`
